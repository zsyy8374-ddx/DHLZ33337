## 信号定义
- **⭐⭐⭐ 软封+早封 (主推)**: 封流比 3-5 + 首封 9:30-10:00 + 排除一字板
- **⭐⭐ 软封其他 (备选)**: 封流比 3-5 + 其他时段 + 排除一字板
- **⛔ 避雷**: 封流比≥5 (任何时间) — 38 天验证全亏

## 基准
- 38 天 OOS (3+4 月): n=65, +3.63% / 66% 胜率
- 4-29 → 4-30 实盘: 8/8 全中, +3.58% / 100% 胜率

## 操作
1. **D 14:55-15:00**: 买入软封+早封档 (单只 ≤15%, 总仓 ≤50%)
2. **D+1 9:30**: 开盘卖出 (T+1 制度, 必须次日)
3. 避雷区**绝不**买入

## 关键: 封流比定义
- **正确**: 涨停封单量 × 100 / 自由流通股 (问财)
- 错误: 封单金额 / 流通市值 (数字小很多, 阈值不可比)
