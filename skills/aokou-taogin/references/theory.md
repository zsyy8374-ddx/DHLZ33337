# 凹口淘金理论详解

## 一、量学理论基础

### 1.1 股数不变定律

量学创始人黑马王子（张得一）提出：在特定价格区间内，筹码数量是固定的。
左侧凹口处有多强的阳柱（买方力量），右侧对称位置就有多强的反弹。
这不是玄学——本质是筹码分布的物理对称性 + 主力成本约束 + 散户行为心理的共振。

### 1.2 三先规律

量学的基石是"三先规律"：
1. **卖在买先**：卖盘是价格的先行指标，卖盘衰竭=底部
2. **价在量先**：价格决定成交量，不是成交量决定价格
3. **庄在散先**：主力行为决定方向，散户行为只是跟随

### 1.3 量柱语言

量柱=市场情绪的量化记录：
- **倍量柱**：量≥前日2倍 → 主力异动信号
- **高量柱**：阶段性最高量 → 市场分歧最大处
- **低量柱（地量柱）**：阶段性最低量 → 市场共识最强处
- **缩量柱**：量连续缩小 → 浮筹减少
- **平量柱**：量与前日持平 → 市场均衡
- **梯量柱**：量逐步放大 → 趋势加速
- **黄金柱**：倍量阳柱 + 后3日价不破其实底 → 主力资金进场标志

## 二、凹口淘金完整形态推演

### 阶段 0：前期走势
- 震荡或缓慢上升，量能平稳，无明显异动
- 时间跨度：至少2-4周

### 阶段 1：突然凹陷（刹车的开始）
- 一根大阴线（跌幅5%+）突然出现
- 必须缩量（≤前20日均量的2/3）
- 看起来像破位，制造恐慌
- 核心验证：缩量 = 主力没跑

### 阶段 2：凹底缩量回调
- 凹陷后继续缩量下探
- 出现地量柱/地量群（百日最低量附近）
- 浮筹被彻底清洗
- 时间跨度：3-10个交易日

### 阶段 3：凹底黄金柱（刹车完成）
- 一根倍量阳柱确立底部
- 次日开始缩量横盘，价格不破倍量阳的实底
- 这就是"卧底黄金柱"——主力资金进场吸筹

### 阶段 4：换挡爬升（加油）
- 连续小阳线缓慢爬升
- 涨幅不超过凹陷深度的1/2
- 量能温和，不放大
- 这是主力在收集筹码，不是拉升出货

常见模式：
- 刹车（倍量阳）→ 换挡（横盘整理）→ 加油（小阳爬升）
- 第二次阳包阴是最安全的介入信号

### 阶段 5：突破平衡线（过峰）
- 股价突破凹口平衡线（以凹陷前最近的大阴实顶为基准）
- 突破方式：
  - 跳空高开（最强）
  - 大阳线突破（强势）
  - 连续小阳突破（稳健）
- 突破时放量但不巨量（放量1.5-3倍为宜，5-6倍巨量=耗竭信号）

### 阶段 6：保顶确认
- 突破后回踩平衡线
- 回踩时缩量
- 不破平衡线
- 横盘整理2-8天
- 这是区分"真突破"和"假突破"的关键一步

### 阶段 7：右侧起跳
- 保顶确认完成后，再次放量拉升
- 这就是凹口的对称位置，凹口淘金的收获期

## 三、关键细节

### 3.1 凹口平衡线的画法

取凹陷前"最近的大阴实顶"画水平线。几种选择：
1. 凹陷第一根大阴线的实顶（最常用）
2. 凹陷前最后一根大阳线的实底
3. 凹陷前平台的筹码密集区

**原则**：取被最多K线触碰验证过的那条水平线。

### 3.2 黄金柱的质量分级

| 等级 | 条件 | 信号强度 |
|:--|:--|:--|
| 黄金柱 | 倍量阳 + 后3日价不破底 | ⭐⭐⭐ |
| 次黄金柱 | 倍量阳 + 后3日价不破底但量放大 | ⭐⭐ |
| 准黄金柱 | 高量阳 + 后3日价不破底 + 缩量 | ⭐⭐⭐ |
| 将军柱 | 倍量阳 + 后3日价破底但收回 | ⭐ |

黄金柱3日后不是最佳介入时机——等到换挡+加油完成后更安全。

### 3.3 假突破的识别

以下信号出现任意一个，判定为假突破：
1. 突破平衡线时放巨量（≥5倍），次日低开
2. 突破后直接跌破平衡线，无保顶动作
3. 保顶期间放量不缩量（主力在出货）
4. 凹底没有黄金柱（纯超跌反弹，不是主力行为）

### 3.4 横勺 vs 斜勺的实战差异

| 维度 | 横勺凹口 | 斜勺凹口 |
|:--|:--|:--|
| 下跌角度 | 陡峭（近乎垂直） | 较缓 |
| 反弹角度 | 同样陡峭 | 缓慢爬升 |
| 凹口形状 | U型/V型 | 斜U型 |
| 量能特征 | 下跌缩量极快 | 下跌缩量渐进 |
| 爆发力 | 极强，容易涨停 | 稳健，趋势延续 |
| 假突破率 | 较高（30-40%） | 较低（15-25%） |
| 适合人群 | 短线高手 | 稳健投资者 |

## 四、实战经验

### 4.1 最容易出凹口淘金的场景
1. 涨停板后回调（涨停凹口淘金）
2. 连续小阳后突然急跌洗盘
3. 板块轮动中被错杀标的
4. 利空出尽后的估值修复

### 4.2 最容易失败的凹口
1. 放量下跌的凹口（火坑）
2. 凹底没有黄金柱的凹口（无主力）
3. 凹口过深（跌幅>30%）的凹口（趋势破坏）
4. 大盘单边下跌中的凹口（覆巢之下）

### 4.3 仓位管理铁律
- 永远不要一把梭
- 三级买入，每级确认后才加仓
- 止损位必须设置且执行
- 凹口淘金的胜率约50-60%，核心是靠盈亏比（止盈:止损 ≥ 2:1）

## 五、选股量化辅助

如果手工程序化筛选困难，优先关注以下统计特征：
1. 近60天最高涨幅 ≥ 9.5%（有过涨停）
2. 最高涨幅日的后续5日平均量能 ≤ 前20日均量的70%
3. 当前价格 ≤ 最高涨幅日收盘价的90%（有回调）
4. 最低回调日的量能 ≤ 百日最低量柱的120%（地量）
5. 当前5日均线方向向上（开始反弹）
