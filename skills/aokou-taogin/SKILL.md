# 凹口淘金战法

## 概述

基于量学（黑马王子）的对称平衡战法。核心逻辑：

> 主力急跌挖坑洗盘（缩量=主力没跑）→ 凹底筑底吸筹（黄金柱确认）→ 右侧对称位置爆发起跳

本质是利用筹码分布的对称性 + 量价关系甄别洗盘 vs 真出货。

## 战法框架

### 六级识别条件（缺一不可）

| # | 条件 | 量化标准 | 否决条件 |
|:--|:--|:--|:--|
| ❶ | 突然凹陷 | 一根大阴线（跌幅≥5%）打破横盘/上升趋势 | 阴线不突显、缓慢阴跌不在此列 |
| ❷ | 首跌缩量 | 凹陷首日的量柱 ≤ 前20日均量的2/3（缩量≥1/3） | 放量下跌 = 主力出货，排除 |
| ❸ | 凹底地量群 | 凹陷区出现地量（≤百日最低量柱的120%），持续3天以上 | 凹底持续放量 = 排除 |
| ❹ | 凹底黄金柱 | 凹陷区底部出现倍量阳柱（量≥前日2倍 + 后3日价不破其实底） | 无黄金柱 = 无主力进场 |
| ❺ | 谷底换挡 | 黄金柱后出现连续小阳爬升（至少3根，涨幅不超过凹陷幅度的1/2） | 反弹过急 = 消耗动能 |
| ❻ | 过峰保顶 | 突破凹口平衡线后，回踩不破、缩量横盘（2-8天） | 跌破平衡线 = 假突破 |

### 两种凹口形态

```
横勺凹口（爆发型）          斜勺凹口（稳进型）
    ┌─┐                       ┌─┐
   /   \                     /   \
  /     \── 平衡线           /     \──── 平衡线
 /       \                 /        
/         \               /    ╱
           ╲             /  ╱
            ╲___        /╱
```

- **横勺凹口**：急跌急涨，右侧直接跳空或大阳突破平衡线 → 爆发力最强
- **斜勺凹口**：急跌缓涨，右侧沿斜线缓慢爬升后再突破 → 更稳健、假突破少

### 买入三级体系

| 级别 | 触发信号 | 建议仓位 | 止损位 |
|:--|:--|:--|:--|
| 试仓 | 凹底黄金柱确认 + 第一次阳包阴 | 1-2成 | 黄金柱实底 -3% |
| 加仓 | 突破凹口平衡线（收盘价站上） | 3-4成 | 平衡线 -2% |
| 重仓 | 过峰保顶完成（回踩平衡线缩量企稳≥2天） | 5-6成 | 平衡线 -2% |

### 卖出规则

- **短线止盈**：突破平衡线后涨幅达凹陷深度的1.0-1.5倍时分批止盈
- **移动止损**：盈利5%后，止损上移至成本价
- **破线清仓**：收盘价跌破凹口平衡线 → 无条件清仓
- **放量滞涨**：上涨中突然放量但不涨 → 减半仓

## 目标筛选流程

### Step 1 — 粗筛候选池

```bash
python3 skills/aokou-taogin/scripts/scan_aokou.py --mode coarse --days 60
```

粗筛条件：
- 近60天内有涨停记录（涨幅≥9.5%）
- 涨停后出现过缩量回调（回调期量柱 ≤ 前20日均量2/3）
- 当前价格处于回调后的相对低位或刚反弹

输出 CSV：`/tmp/aokou_coarse.csv`

### Step 2 — 精筛形态识别

```bash
python3 skills/aokou-taogin/scripts/scan_aokou.py --mode fine --input /tmp/aokou_coarse.csv
```

对每只候选股逐项打分（六级条件每项 0-1分，满分 6分）：

| 得分 | 级别 | 含义 |
|:--|:--|:--|
| ≥5.0 | ⭐⭐⭐ S级 | 标准凹口淘金，六条件基本满足 |
| 4.0-4.9 | ⭐⭐ A级 | 大概率凹口淘金，关键条件满足 |
| 3.0-3.9 | ⭐ B级 | 部分条件满足，需继续观察 |
| <3.0 | — | 不符合，排除 |

### Step 3 — 量学细节确认

对 S/A 级候选，人工/模型逐只核对：

1. 画凹口平衡线：取凹陷前最近的大阴实顶（或大阳实底）
2. 确认凹底黄金柱质量（后3日缩量不破底 > 后3日平量 > 后3日微增量）
3. 确认换挡动作（刹车→换挡→加油三步骤是否完整）
4. 判断凹口类型（横勺 vs 斜勺，横勺优先）
5. 当前处于哪个阶段（筑底期 / 换挡期 / 突破期 / 保顶期）

### Step 4 — 输出报告

按三级买入信号输出选股报告，格式：

```
📐 凹口淘金选股报告 — YYYY-MM-DD

🔥 S级（评分≥5.0）：可考虑试仓
| 代码 | 名称 | 评分 | 凹口类型 | 当前阶段 | 平衡线价格 | 当前价格 |
|------|------|------|----------|----------|------------|----------|

⭐ A级（评分4.0-4.9）：关注、等待信号确认
| 代码 | 名称 | 评分 | 缺哪个条件 | 建议观察什么 |

📌 B级（评分3.0-3.9）：列入观察池
```

## 与其他战法叠加

凹口淘金可以与以下战法叠加使用，信号强度翻倍：

| 叠加战法 | 叠加方式 | 增强逻辑 |
|:--|:--|:--|
| 回马枪 | 凹口形态 + 涨停日距离2-10天 | 回调形态+量学确认 |
| 一进二打板 | 凹口突破日 = 涨停日 D0 | 形态突破+隔夜溢价 |
| N字战法 | 凹口形态 = N字左腿+坑+右腿 | 量学框架下的N字 |

叠加时，两个战法各打分，总分=凹口分×0.6 + 叠加战法分×0.4。

## 注意事项

1. **火坑 vs 金坑**：放量下跌的凹陷 = 火坑（主力出货），缩量下跌 = 金坑。这是第一道关口。
2. **大盘环境**：熊市末期+震荡市 = 凹口淘金最佳行情。单边下跌市不要用。
3. **流通市值**：优先 20-100亿，太小容易被操纵，太大凹口形态不显著。
4. **不追已突破**：凹口平衡线以上追高 = 放弃保顶确认 = 风险翻倍。宁可错过，不做火坑。
