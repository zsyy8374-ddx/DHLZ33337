# 紫苏雷达 🍃

基于「紫苏叶理论」的 A 股上游卡点公司扫描与分析系统。

## 方法论来源

紫苏叶理论核心方法论：

- **紫苏叶理论：** 不买行业巨头/整机厂，专找产业链最不起眼、最不可替代的上游环节
- **操作路径：** 从下游资本开支反推 → 往上游一层层推到"拿走整条链就卡住"的环节 → 提前 6-12 月布局
- **选股标准：** 小市值（优先 < 200亿，上限 300亿）、无人覆盖/被市场忽视、供应瓶颈具物理约束（扩产周期长）

### Step 0：关键词矩阵（搜索前必须先拆）

⚠️ **2026-07-15 订单雷达教训移植**：单条宽泛搜索词（如「AI音箱 上游 卡脖子」）搜出来全是行业综述，打不穿产业链各环节。必须在搜索前把主题拆成**产业链环节级关键词矩阵**。

**拆法**：把主题按产业链环节拆成独立搜索词，每个环节单独搜：
```
不是搜：「AI音箱 上游 国产替代 A股」
而是拆成：
  「MEMS麦克风 国产替代 A股 龙头」
  「微型扬声器 芯片 国产替代 A股」
  「智能音箱 AI处理器 芯片 国产替代」
  「微型驱动 线性马达 A股 供应商」
  「音频ADC芯片 国产替代 A股」
```

**规则**：
- 主题 ≤ 2 个产业链环节 → 拆 3-5 个关键词
- 主题 ≥ 3 个产业链环节 → 每个环节至少 1 个独立搜索词
- 每个搜索词必须包含：细分产品/技术名 + 国产替代/A股/龙头
- **先拆词，再搜。不可跳过。**

### Step 1：产业链拆解
从下游终端需求反推上游，拆出 3-5 层产业链，标注每个环节的卡脖子程度（★越多越卡）：
- 问：这个环节拿走，整条链就停了吗？
- 问：这个环节的供给有没有物理约束（扩产周期 > 18个月、认证周期 > 2年）？
- 问：国产化率多低？（< 30% 才是真正的卡点）

### Step 2：A 股标的筛选
在每个卡脖子环节找出 A 股对应公司。筛选标准：
- 国内稀缺甚至唯一（没有同等替代品）
- 有认证壁垒（如 ASML 认证、台积电供应链、FDA/CE 认证）
- 扩产周期长（18 个月+）
- 下游需求刚性（没有它产线就停）
- 市值偏小但技术壁垒深（优先 < 200亿）
- 被市场忽视/研报覆盖少

每个环节选 1-2 只标的，总共 5-7 只。

### Step 2.5：防漏检查（定稿前强制执行）

⚠️ **2026-06-28 硅微粉事故 + 2026-06-29 创新药漏标事故教训**

产业链拆解完后，必须自问三句：
1. "这个主题除了我想到的环节，从**最终产品**反推，还有哪些相关材料/耗材/设备细分被卡脖子？"
2. "我推的产业链是从A到B到C——中间有没有跳过环节？"
3. "我是否同时覆盖了前道和后道？制造和封装？材料和设备？"

补扫搜索词：
```bash
python3 tools/search.py "<主题> 上游 耗材 卡脖子 A股 国产替代" 10
python3 tools/search.py "<最终产品> 上游 材料 设备 耗材 国产替代 A股" 10
```

标注"已通过防漏检查 ✅"后才能进入四视角评分。

### Step 3：四视角深度分析
对每只候选标的输出（今日最新数据）：

**📈 技术面（评分 X/10）**
- 今日收盘价、涨跌幅、市值
- K 线形态、近期高低点、支撑压力位
- 量价配合判断

**💰 资金面（评分 X/10）**
- 营收/利润/增速/毛利率/净利率
- PE/PB 估值分位
- 研发投入、产能规划
- 机构预测与覆盖

**🧠 情绪面（评分 X/10）**
- 核心竞争壁垒（认证/专利/市占率/客户依赖度）
- 近期利好利空对照
- 机构调研/研报动态
- 与可比公司的差异优势

**📡 题材面（评分 X/10）**
- 与主题产业政策的直接关联度
- 国产替代空间（当前国产化率？）
- 下游需求确定性与增速
- 催化剂事件时间表

**📌 综合评分 = 四项之和（满分 40）+ 一句话总结 + ⚠ 风险提示**

### Step 4：横向比较
生成横向对比表，按紫苏叶纯度（1-10）和综合评分排名：
- 紫苏叶纯度 = 该标的有多符合"小而美、不可替代、上游卡脖子"的标准
- 评分越高 → 推荐优先级越高
