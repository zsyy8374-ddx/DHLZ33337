# 趋势顶底RSI三线组合战法 — 完整规则

## 一、趋势顶底定区域

TDX 公式源码：
```
A:=MA(-100*(HHV(HIGH,34)-CLOSE)/(HHV(HIGH,34)-LLV(LOW,34)),19),COLORRED;
B:=-100*(HHV(HIGH,14)-CLOSE)/(HHV(HIGH,14)-LLV(LOW,14));
D:=EMA(-100*(HHV(HIGH,34)-CLOSE)/(HHV(HIGH,34)-LLV(LOW,34)),4),LINETHICK2;
长期线:A+100,COLOR9900FF;
短期线:B+100,COLOR888888,COLORRED;
中期线:D+100,COLORYELLOW,LINETHICK2;
```

解读：指标值 = 价格在 N 日高低区间内的相对位置（0-100）
- 高值 → 价格在区间上沿（强势/超买）
- 低值 → 价格在区间下沿（弱势/超卖）

**五区划分**：
- <20: 底部观察区 — 只看不急买
- 20-50: 修复区 — 观察转强信号
- 50 附近: 强弱分界
- 50-80: 强势运行区 — 适合持股、回调低吸
- >80: 高位风险区 — 不宜追涨

## 二、RSI三线定动能

- RSI6: 短线情绪，寻找短线拐点
- RSI12: 波段节奏，判断动能是否转强
- RSI24: 中期强弱，过滤假信号

**强势**: RSI6 > RSI12 > RSI24，三线在 50 上方
**弱势**: RSI6 < RSI12 < RSI24，三线在 50 下方

RSI24 仍在下行时，短线金叉容易失败。

## 三、均线和成交量定买点

- 股价站上 5/10 日线，20 日线走平或向上
- 回调不有效跌破 20 日线
- 突破放量 ≥ 近 5 日均量的 1.3-2 倍
- 无清晰止损位不买

## 四、底部反转战法

**条件**：
1. TTB 在 20 附近开始拐头向上
2. RSI6 上穿 RSI12，RSI12 走平向上
3. 放量站上 10 日线或突破下降趋势线

**激进买点**：RSI6 金叉 RSI12 + 放量站上 10 日线
**稳健买点**：RSI12 上穿 50 + 站上 20 日线
**止损**：跌破最近低点 / RSI6+RSI12 再次死叉跌回 50 下方

## 五、强势回调战法 ★ 推荐

**条件**：
1. TTB 在 50-80 强势区，RSI24 > 50 向上
2. RSI 三线多头排列
3. 回调缩量，不有效跌破关键均线
4. RSI6 回落接近 RSI12 后再次上穿
5. 放量阳线站上 5/10 日线

**止损**：跌破 20 日线且放量 / RSI12 跌破 50 / 跌破回调低点

## 六、平台突破战法

**条件**：
1. 横盘 10-20 个交易日
2. TTB 从 20-50 修复到 50 附近
3. RSI12 > 50，RSI24 走平向上
4. RSI 三线逐步多头排列
5. 放量突破平台上沿

**止损**：跌回平台内部 / 突破后 2-3 天无法继续放量

## 七、高位减仓战法

**减仓**：TTB > 80 拐头 + RSI6 下穿 RSI12 + 放量长上影/阴线
**离场**：顶背离 + 跌破 20 日线 + RSI24 拐头向下

## 八、完整买卖模板

### 买入模板
1. TTB 从底部区走出 或 在 50-80 强势区
2. RSI24 走平向上，尽量在 50 上方
3. RSI12 上穿或站稳 50
4. RSI6 上穿 RSI12 或回踩 RSI12 后再次上攻
5. 股价站上 10/20 日线
6. 突破放量
7. 止损位清晰

### 卖出模板
1. TTB > 80 后拐头
2. RSI6 高位下穿 RSI12，RSI12 也开始向下
3. 跌破 5/10 日线
4. 放量长上影/阴线/顶背离
5. 跌破 20 日线
6. RSI24 拐头向下

## 九、实战口诀

- 趋势顶底看区域，RSI三线看动能，均线成交量看买点
- 底部区只代表可能便宜，不代表马上上涨
- 80 以上不盲目追涨
- 三线同向，信号最强；三线打架，少动为好
- 强势股买回调后的再上攻
- 先想亏多少，再决定买多少
