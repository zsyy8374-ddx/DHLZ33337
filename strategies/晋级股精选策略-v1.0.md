# 晋级股精选策略 v1.0
**目标：从当日涨停池（50-100 只）中精选出 3-5 只"次日大概率晋级（首板转 2 板 / 2 板转 3 板）"的高胜率标的**
**作者：dengxian for Shi**
**版本：v1.0 (2026-04-28 创建，基于实战经验 + 多源资料融合)**

---

## 〇、核心认知 (Mindset)

### 1. 这是概率游戏，不是确定性游戏
- 全市场连板晋级率历史均值 **25-35%**，牛市最高 50%，退潮期低至 15-20%
- 4/28 当日：59 涨停 / 11 连板 / 破板率 18.30% — 属"中性偏弱"
- **3 只命中 1 只就算成功；命中 2 只就是盈利来源；命中 3 只是运气**
- 不要追求"必中"，而要追求"赔率 × 胜率 > 1"的正期望系统

### 2. 必须分清三种市场情绪期
| 情绪期 | 特征 | 策略 |
|---|---|---|
| **冰点低迷期** | 连板高度 ≤3 板，破板率 >25% | 低吸首阴 / 反包板，**不打板** |
| **混沌活跃期** | 连板高度 4-5 板，破板率 15-25% | 主线龙 + 卡位二板，**主战场** |
| **高潮分化期** | 连板高度 ≥6 板，破板率 <15% | 只做主线龙，警惕高度回踩 |

**当前 4/28：连板高度 8 板（金螳螂） + 破板率 18.30% → 高潮分化期早期**
→ 策略应聚焦"主线低位 1-2 板"，**避开 6 板以上高度票**

### 3. 模式优于直觉
任何"觉得这只票明天会涨"的判断都不要做。
**只做模式内的交易**，每一步必须有量化打分支撑。

## 一、晋级股六维评分体系（核心，权重总分 100）

每只候选股按以下 6 个维度打分，**总分 ≥ 75 分** 才进入备选池，**总分 ≥ 85 分** 才进入实盘候选。

### 维度 1：题材纯度 (25 分) — 最重要
- 当前市场主线（连板≥3只 + 板块涨幅领先）：**满分 25**
  - 例：4/28 主线 = 国产芯片 / 算力 / 氢气
- 主线相关支线（连板 1-2 只）：15 分
- 蹭概念 / 多概念混搭 / 老题材：5 分
- 纯业绩驱动（无题材）：0 分
- ⚠️ **扣分项**：业绩雷风险 / 即将披露未披露财报 → -10
- ⚠️ **加分项**：今日板块净涨幅 ≥3% + 板块龙头一字板 → +5

### 维度 2：封板时间 (20 分)
- 9:30-9:45 早盘秒板 / 一字板：**满分 20**
- 9:45-10:30 早盘强势板：15 分
- 10:30-13:00 上午尾盘 + 午后开盘板：10 分
- 13:00-14:30 午后回封板：5 分
- 14:30-15:00 尾盘抢板：**0 分**（次日大概率高开低走）
- ⚠️ **扣分项**：盘中炸板 ≥2 次 → -10

### 维度 3：位置高度 (15 分)
- 首板（1 板）：12 分（注意：首板转 2 板成功率约 30%）
- 2 板：**满分 15**（2 板转 3 板成功率最高，约 35-40%）
- 3 板：12 分
- 4 板：8 分
- 5 板：5 分
- 6 板：2 分
- ≥7 板：**0 分**（高度区，回踩风险大）
- ⚠️ **加分项**：断板后反包 1 板（断板复活）→ +3

### 维度 4：资金强度 (15 分)
**封流比**（封单金额 / 流通市值）—— 当前最重要的实盘指标
- 封流比 ≥ 3%：**满分 15**（主力深度锁仓）
- 封流比 1.5-3%：12 分
- 封流比 0.5-1.5%：8 分
- 封流比 <0.5%：3 分
- 封流比 <0.2%：0 分（弱封板，次日大概率开板）

**封成比**（封单金额 / 当日成交金额）—— 辅助
- 封成比 >10：高开 ≥5% 概率 70%
- 封成比 3-10：高开 3-6%
- 封成比 <1：基本不会高开

### 维度 5：龙虎榜信号 (15 分) — 盘后才能算
**席位识别（5 分一档）：**
- 顶级游资+机构同步进入（章盟主/葛老大/作手新一+机构）：**满分 15**
- 顶级游资单独进入（紫阳东路/相城大道/小棉袄/方新侠）：12 分
- 一线游资进入（华鑫上海/华源江苏/国泰海通分公司）：8 分
- 仅深股通 + 量化打板席位：5 分
- 仅有"量化进+量化出"对倒：0 分
- ⚠️ **扣分项**：温州帮 / 北京帮 出现在卖方席位 TOP3 → -5
- ⚠️ **扣分项**：龙虎榜显示净卖出（卖>买） → -10
- 没上龙虎榜：默认 0 分

**资金风格匹配：**
- 章盟主+作手新一类锁仓游资 → 次日溢价高
- 量化打板席位为主 → 次日多数砸盘
- T+0 王 / 散户席位为主 → 弱

### 维度 6：流通盘 + 量能配合 (10 分)
**流通市值（5 分）：**
- 30-80 亿：**满分 5**（小资金能拉，机构也愿意接）
- 20-30 亿 或 80-150 亿：3 分
- <20 亿（微盘）：1 分（注意监管异动）
- >150 亿：1 分（大盘股弹性差）

**量能（5 分）：**
- 缩量涨停（成交 <昨日 70%）：**满分 5**（筹码锁定好）
- 适度放量（成交 100-150% 昨日）：4 分
- 巨量涨停（成交 >2 倍昨日）：2 分（次日抛压大）
- 天量涨停（换手率 >25%）：0 分（顶部信号）

## 二、6 个一票否决项（红线）

任何标的命中以下任意一项，**直接踢出候选池**，不论评分多高：

1. ❌ **次日临时停牌 / ST 戴帽 / 退市风险** — 公告必查
2. ❌ **业绩雷**：当晚或次日开盘前披露巨亏 / 商誉暴雷
3. ❌ **临近异动监管** ：连续 3 个交易日累计涨幅 >20% 且无新利好
4. ❌ **大股东减持 / 解禁** ：减持公告 + 大额解禁未消化
5. ❌ **地天板 / 烂板**：当日盘中曾跌 -5% 以上才拉到涨停
6. ❌ **题材已被官方否认 / 利好兑现**：如公告"未与 XX 合作"等

## 三、操作执行流程（每日固定动作）

### 📅 T 日（盘后 15:00-22:00 北京时间）

**Step 1: 数据采集（15:00-16:00）**
- [ ] 抓取当日全部涨停股清单（用九阳公社/同花顺/PDF）
- [ ] 重点字段：代码、板数、涨停时间、流通市值、成交额、概念关键词、题材分组

**Step 2: 板块情绪诊断（16:00-16:30）**
- [ ] 涨停总数 / 跌停总数 / 连板总数 / 破板率 → 判断情绪期
- [ ] TOP3 板块识别 + 各板块连板梯队（主线必须有≥3 只涨停）
- [ ] 龙头是否走强（高度板是否封死 / 炸板）

**Step 3: 龙虎榜复盘（17:30-18:30，等数据出齐）**
- [ ] 抓当日机构净买入 TOP10
- [ ] 抓顶级游资动向（章盟主、葛老大、紫阳东路、作手新一等）
- [ ] 标记每只候选股的席位

**Step 4: 六维打分 + 一票否决筛选（18:30-20:00）**
- [ ] 逐只候选股填评分卡（见附录 A）
- [ ] ≥75 分进备选池，≥85 分进实盘候选
- [ ] 排序：总分 → 维度 1（题材）→ 维度 2（封板时间）

**Step 5: 输出明日操作计划（20:00-21:00）**
- [ ] 推荐 3-5 只标的，按优先级排序
- [ ] 每只标注：开仓价位区间、止损位、仓位上限
- [ ] 提示风险：开盘怎么走才打 / 怎么走就放弃

### 📅 T+1 日（盘前 + 盘中）

**盘前竞价（北京 9:15-9:25）**
- [ ] 看竞价开盘价：低开 -2% 到平开是最佳介入区间
- [ ] 高开 >5% → 大概率冲高回落，不打 / 等回踩
- [ ] 低开 -3% 以上 → 题材发酵失败，放弃

**盘中（9:30-15:00）**
- 优先打"竞价 → 9:35 之前快速上板"的票
- 严守纪律：3 天不创新高无条件减仓
- 严守止损：跌破今日涨停价 / 跌破 5 日均线

**盘后**
- [ ] 复盘命中率，每只票记录"为什么对 / 为什么错"
- [ ] 沉淀成功因子 → 修订评分权重

## 五、特殊战法（高级，备用）

### 战法 1：龙头身位战 (适用：高潮分化期早期)
- **只买当日板块最高板的"身位龙"**（如金螳螂这类 8 板高度龙）
- 但要求：早盘秒板 + 封流比 >3% + 章盟主级别游资进入
- 风险高赔率高，仓位 ≤ 10%

### 战法 2：低位卡位二板战 (适用：混沌活跃期)
- **首板转 2 板的"卡位龙"**（如 4/28 的格林达、铭普光磁）
- 要求：题材主线 + 早盘板 + 流通 30-80 亿 + 板块梯队完整
- **本策略主战场，仓位 60-70%**

### 战法 3：弱转强反包战 (适用：冰点低迷期)
- 昨日炸板 / 大烂板的票，今日竞价超预期高开放量
- 要求：换手率 ≥20% + 5 日均线支撑 + 板块情绪修复
- 高难度，仓位 ≤ 15%

### 战法 4：补涨低位战 (适用：板块第一波结束)
- 板块龙头已 4 板以上，板块内低位同概念股启动
- 目标：龙头空间 50-80%
- 仓位 ≤ 25%，目标 1-2 板溢价兑现

## 八、给 Shi 的实操提醒

1. **永远不重仓追**：单票仓位上限 30%，候选 3-5 只总仓位 ≤ 75%
2. **永远盘前下决定，盘中只执行**：盘中临时起意 = 90% 亏钱
3. **永远止损先行**：跌破涨停价无条件出
4. **不在情绪期错位时强打**：高潮分化期就降低仓位，冰点期就空仓等待
5. **每周复盘命中率**：低于 30% 立即减仓 / 检讨策略
6. **不复制别人的票**：研报推荐的票当天就被透支了，要找研报里没出现的低位龙
