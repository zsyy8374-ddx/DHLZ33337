### v7 失败的工程教训 ⭐

1. **akshare 单点接口 < 5 板块/秒**, 363 板块全量拉 = 致命瓶颈
2. **nohup / setsid 后台跑** 在 OpenClaw 容器里依然会被父进程退出影响, 不是真完全脱离
3. **stdout 缓冲 + \r 进度条** 在 log 文件里只看到 28 行 (其实跑了几百次), 难调试
4. **正确做法**:
   - 先做"门控" (热度 ≥ 阈值才拉指数)
   - 用 `concurrent.futures` 并发 + 失败容错
   - 进度条改用 `\n` 行, 不要 `\r`
5. **当前结论**: v7 暂搁置, **v6 已经够用 (lift 2.85x), 先做多日验证**
