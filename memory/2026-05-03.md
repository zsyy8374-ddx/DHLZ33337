   - 进度条改用 `\n` 行, 不要 `\r`

### 我现在能用的字段 (跟封单/涨停相关):

|---|---|---|---|

**调用语法**:

```
封单金额:GPJYVALUE(15,2,2);       {收盘封单金额, 跟问财的"涨停封单额"等价}
```

### 关键: "最大封单额" vs "收盘封单额" 区别 ⭐

- **问财"涨停封单额"** = 收盘那一刻的封单 (静态)
- **GPJYVALUE(24,2,2) "最大封单额"** = 盘中**任何时刻**出现过的最大封单 (动态峰值)

**为什么峰值比收盘重要**:
- 一只票 10:00 封板封单 5亿 → 14:00 撬开 → 14:30 重封 1亿收盘
  - 收盘封单额: 1亿 (看起来弱)
  - 最大封单额: 5亿 ⭐ (告诉你曾经有过强主力)
- 反之, 一字板早上封死, 全天封单一直在 1亿
  - 收盘封单 = 最大封单 = 1亿 (一致, 真封)

**= 最大/收盘 比值** 能告诉我"封板硬度变化":
- 比值 ≈ 1: 持续封死, 真封板
- 比值 >> 1 (如 5x): 盘中撬过, 主力撤过单
- 比值很小 (<0.5): 罕见, 异常

### 与 v3.0 公式的整合

v3.0 牛股启动雷达里**封单数据**这一项现在用的是**收盘**封单, 应该改为:
```
封单评分 = MIN(收盘封单额, 最大封单额) × 流通比 × 持续度
持续度 = 收盘封单额 / 最大封单额  ← 新指标
```

### 板块强度 v0.2 也能用上

刚才板块分析里我用 **首封时间 + 炸板次数**, 现在加上:
- **板块平均最大封单额**: 真有主力的板块
